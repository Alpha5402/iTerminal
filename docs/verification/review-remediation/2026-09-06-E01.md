# E01 bounded WS observation — 2026-09-06

## Revision and method

Candidate: integration diff after `5c59a49ed034bb3d6e59231a4c3e93f20128d4ea`, macOS arm64 Apple M5, Node v24.15.0. Temporary instrumented source files and owned PTYs are cleaned by the scripts. Raw JSON remains in ignored local artifacts; the measured values are retained here.

`pnpm exec tsx scripts/benchmark-console-stream.ts --output=docs/verification/review-remediation/artifacts/stream.json` materializes the exact baseline Console server from Git, running baseline and current server against the same current Runtime backend. Each mode uses its own real PTY and fast-ACK WS client: 1500 ms idle, then 50 numbered lines at 20 ms, then final observation. Both clients actually received the final line and observed COMPLETED. This compares Console transport changes, not two complete historical deployments.

| Metric                                                          | Baseline Console | Canonical Console |
| --------------------------------------------------------------- | ---------------: | ----------------: |
| Idle messages / screen payloads                                 |            2 / 2 |             2 / 1 |
| Idle bytes                                                      |             4068 |              6312 |
| Total WS messages                                               |               57 |                40 |
| Total screen/full-or-delta payloads                             |               57 |                38 |
| Total UTF-8 WS bytes                                            |           137795 |            446221 |
| Gateway calls (includes screen waits and close-time Guard read) |              230 |               120 |

Canonical mode reduced calls/frames here but increased bytes because normalized styled cells replace plain text. There is no bandwidth-saving claim. The first measurement used the wrong delta ACK field in the benchmark client and was discarded; this report uses actual delta application and its frame version.

## Contract and tests

Default 30 fps (composition option 1–60), one unacknowledged frame, latest pending frame only, five-second render-ACK resync timeout, acknowledged same-geometry delta baseline, full reconnect fallback. Screen/interaction metadata are explicitly non-atomic with durable events; event cursor never skips undelivered facts. Delayed events produce partial/lag while screens continue, with one event read and AbortSignal cleanup.

`stream-observation.test.ts` covers coalescing, stale/future ACK, complete delta reconstruction, delayed event reads and cancellation, a never-rendering client and unsupported capability fallback. Required real Browser+official MCP scenarios and full regression are recorded in [final verification](2026-09-06-final-verification.md). Level L3 for named shared paths plus the local slow-consumer fault case.

## Not proven

A stalled subscriber was tested for the bounded timeout, not hours of socket-pressure soak. No browser paint percentile is measured. The current backend is used in both transport modes; counts are one bounded run. Canonical observation still incurs styled-cell serialization, especially on scroll-heavy screens.
