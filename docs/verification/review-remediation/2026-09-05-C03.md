# C03 input-context uncertainty verification

- Baseline: `ce65f3b`
- Branch: `codex/remediation-c03-input-uncertainty`
- Evidence: L1 + L3 isolated browser path.

Implemented a pure Console mapper for the existing `untracked_input` and `delivery` reasons. The UI preserves the frozen draft and remains fail-closed for line input. `untracked_input` explains that Raw Input, Control, or Secret input may have changed the program buffer and exposes exact-session Raw keys, current Execution, and guarded Ctrl-C actions. `delivery` warns that delivery is uncertain and must be reconciled using the existing intent/Action identity rather than a new idempotency key. No protocol/state transition/reset/secret-byte changes were made.

The dedicated PostgreSQL 17 tmpfs container `iterminal-c03-postgres` on `127.0.0.1:55502` (`iterminal_test`) was used. The final browser suite passed 10/10, including the independent uncertainty/delivery/old-target flow and Secret finish flow. No user runtime, PTY, or database was accessed.
