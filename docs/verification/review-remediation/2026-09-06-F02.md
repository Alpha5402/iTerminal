## Correctness and corrected attempts

Long output is framed by a separate fixture script. Tests retain the entire merged PTY output,
extract only the marked payload for length/SHA-256 comparison and do not remove shell echo/prompt
from Runtime output. The compact path pages until completion with a bounded call budget.

The handoff's four failures were test assumptions: comparing a complete PTY transcript against
only payload, using Ctrl-C as if it exits Python, and expecting FAILED for a completed nonzero
command. These were corrected to framed payload verification, `exit()` and COMPLETED/exitCode=1.
Earlier failing metrics are not correctness-qualified comparisons.

Discarded response means the fixture intentionally ignores an already received result; it is not
an actual broken wire. It then queries the original Action and confirms one side effect. Existing
real wire-loss/crash tests independently cover uncertain delivery. Expired artifact reads must
return expired/gap rather than a false complete transcript.

## Suggested model trial

In a separately authorized isolated Session, ask a model to run the same short, long, REPL and
sustained fixtures using finite waits; retain the exact execution identity and output cursor,
query the Action after uncertainty, and never reissue unknown work under a new key. Record the
provider's actual usage separately from this deterministic fixture. No such trial was purchased
or run for this report.
