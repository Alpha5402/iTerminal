## 后续提案触发条件

| 提案                            | 只有这些事实出现时再立项                                                   | 当前边界                                           |
| ------------------------------- | -------------------------------------------------------------------------- | -------------------------------------------------- |
| READY 原生编辑 / Tab completion | 真实用户任务必须依赖 Shell readline/ZLE completion，现有命令编辑器不能满足 | 不宣称当前 READY composer 是完整 Shell 编辑器      |
| 完整 VT / 鼠标 / 图片 / 超链接  | 明确程序在当前 canonical cells 路径受阻，并有可复现样例                    | 当前覆盖颜色、宽字、软换行、受控输入；不是全部 TUI |
| 离线写入                        | 有明确持久化与 fencing 设计能在故障时证明唯一执行权                        | 目前数据库不确定时不继续写 PTY，UNKNOWN 不重放     |
| Session ACL 实施                | 多 Agent 真实任务需要不同 Session 可见/可写范围                            | F03/ADR 0081 仅为 opt-in 设计，不改变当前 grants   |
| 可配置执行 deadline             | 实际任务需要明确运行寿命，并定义取消和进程树回收                           | 等待超时只结束观察，不杀执行                       |
| 更低投影延迟                    | 实际负载复现约 1.4 秒的高吞吐积压并构成用户阻塞                            | 先保留测量，再评估快照调度，不能丢版本换指标       |

RabbitMQ、多 owner、故障演练等既有模式保留为可选能力；本轮没有新增数据库、缓存服务或微服务拆分。普通 verify 的可选 skip 不计作必选门禁成功，也不表示 repository release L4 已完成。
